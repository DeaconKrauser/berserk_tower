name: bastiao-visual-quality
description: Visual polish and dark fantasy presentation rules for Bastiao. Use for maps, roads, tiles, props, towers, lighting, particles and any visual polish.
---

Maintain a cohesive dark fantasy pixel-art visual language.

Use:
- Pixel Perfect Camera
- PPU 32
- FilterMode.Point
- no sprite smoothing
- consistent pivots
- Y sorting for units

Prioritize:
1. silhouette readability
2. gameplay readability
3. animation clarity
4. visual polish

Use subtle:
- 2D lights
- particles
- decals
- hit flashes
- blood/dust effects
- ambient motion

Avoid:
- excessive bloom
- excessive screen shake
- large opaque UI panels
- effects that hide enemies
- excessive dynamic lights per enemy

Bosses should feel visually heavier through:
- scale
- animation
- sound
- particles
- restrained camera feedback

not by simply enlarging a static image.
